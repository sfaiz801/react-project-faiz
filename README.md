# React Bootstrap Dashboard - Type 1

A modern, responsive React application showcasing React Bootstrap components and UI patterns. This project demonstrates best practices in building interactive dashboards with reusable components.

## 📋 Project Overview

This is a comprehensive React Bootstrap component library dashboard featuring:

- **Interactive Components**: Accordion, Cards, Modal, Carousel, Forms, Dropdowns, and more
- **Responsive Design**: Mobile-first approach with Bootstrap's responsive grid system
- **Form Validation**: Complete form validation with error handling
- **Modern Tech Stack**: React 18+, Vite, React Bootstrap, React Router

## 🎯 Features

### Non-Interactive Components
- **Badges** - Status indicators and badges
- **Breadcrumbs** - Navigation breadcrumb trails
- **Button Groups** - Grouped button layouts
- **Buttons** - Various button styles and states
- **Cards** - Content container cards
- **Figure** - Image figure components
- **Images** - Responsive image handling
- **List Groups** - Styled list components
- **Pagination** - Navigation pagination
- **Progress Bars** - Progress indicators
- **Spinners** - Loading spinners
- **Tables** - Data table display

### Interactive Components
- **Accordion** - Collapsible content sections
- **Carousel** - Image carousel/slider
- **Dropdowns** - Dropdown menus
- **Forms** - Complete form with validation
- **Modal** - Modal dialogs
- **Navbar & Offcanvas** - Navigation bars
- **Nav Tabs** - Tabbed navigation
- **Overlays** - Tooltip and popover overlays

## 🛠️ Tech Stack

- **Frontend Framework**: React 18+
- **Build Tool**: Vite
- **UI Library**: React Bootstrap 5
- **Routing**: React Router v6
- **Icons**: React Bootstrap Icons
- **State Management**: React Hooks (useState)
- **Styling**: Bootstrap CSS + custom utilities

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sfaiz801/react-project-faiz.git
   cd react-project-faiz
   ```

2. **Switch to development branch**
   ```bash
   git checkout development
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Build for production**
   ```bash
   npm run build
   ```

## 🚀 Getting Started

The application runs on `http://localhost:5173` by default.
